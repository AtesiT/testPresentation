# ⚛️ Аппроксимация широкодиапазонного уравнения состояния (EOS) алюминия с помощью PINN
Репозиторий содержит готовое научноёмкое решение первого Кейса хакатона Росатом. В основе проекта лежит создание **физически-информированной нейросети (PINN)** для термодинамически согласованного моделирования зависимости Давления ($P$) и Внутренней энергии ($e$) от Плотности ($\rho$) и Температуры ($T$).

---

## Результаты бенчмаркинга моделей
Для оценки эффективности были сопоставлены три подхода: классический Baseline (интерполяция), стандартная полносвязная нейросеть (Vanilla NN) и разработанный PINN с контролем скорости звука. 

Валидация проводилась на независимой тестовой выборке (20% от общего датасета в 1.1 млн строк).

| Модель (Model Approximator) | R² (P, log₁₀) | Медианная относительная ошибка P | p95 | R² (e) | Термодинамические ограничения | Размер | Время на запрос |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Baseline (билинейная интерполяция, 20 регионов)** | 1.00000 | 0.0000 % | 0.0000 % | 1.00000 | нарушено в 2.86 % точек (разрывы производных) | 17.2 МБ таблицы | 0.56 мкс |
| **Vanilla MLP (2→128→128→64→2)** | 0.99915 | 5.69 % | 25.3 % | 0.99979 | нарушено в 31.87 % точек | 0.100 МБ | 0.91 мкс |
| **Финальный PINN (данные + физика)** | 0.99865 | 8.94 % | 28.2 % | 0.99953 | **нарушено в 0.43 % точек** | 0.100 МБ | 0.95 мкс |

Валидация — 20 % независимой выборки (226 011 точек) из 1 130 053 строк датасета.
Нарушения считаются по autograd-производным на 100 тыс. точек: ∂P/∂ρ > 0, ∂e/∂T > 0, 0 < c_s < c.

*Вывод:* Vanilla-сеть точнее попадает в табличные значения, но её производные физически некорректны в каждой третьей точке — гидрокод получит мнимую скорость звука. **PINN осознанно уступает 3 п.п. медианной точности и снижает долю нарушений в 74 раза** (с 31.87 % до 0.43 %), оставаясь в пределах 0.1 МБ.

## Как обучалась финальная модель

1. **Этап данных** (120 эпох): MSE по log₁₀P и e в нормированном пространстве, Adam + OneCycle, batch 8192.
2. **Этап физической калибровки** (44 эпохи): добавляются ReLU-штрафы за ∂P/∂ρ < 0, ∂e/∂T < 0 и выход c_s из (0, c); γ = 0.3 → 0.12, lr ≤ 3·10⁻⁴.
3. **Маска разрывов**: физические штрафы считаются только вне стыков региональных сеток (9.6 % точек), иначе сеть «борется» с нефизичными скачками самой таблицы.
4. **Стабилизация**: клиппинг градиента, откат шага при NaN, выбор лучшей эпохи по валидации.

Скорость звука сверена с табличной: R² = 0.90 по log₁₀ c_s, медианное отклонение 11.7 %; точек с c_s ≥ c нет.

## Реализованные физические ограничения (PINN Loss)
В граф вычислений PyTorch через подмодуль `torch.autograd.grad` внедрены фундаментальные термодинамические критерии:
1. **Критерий устойчивости Максвелла:** Подавление отрицательных значений производной давления по плотности ($\frac{\partial P}{\partial \rho} > 0$), страхующее модель от нефизичного самопроизвольного сжатия.
2. **Контроль знака теплоёмкости:** Удержание строго положительного знака изменения энергии по температуре ($\frac{\partial e}{\partial T} > 0$).
3. **Критерий скорости звука:** Контроль вещественности и дорелятивистских рамок скорости звука ($0 < c_s < c$).
